⚡ QuizMaster Pro – Smart Online Quiz Application

📌 About the Project

QuizMaster Pro is a responsive online quiz application developed using HTML, CSS, and JavaScript. It helps users test their knowledge through interactive quizzes, multiple categories, automatic scoring, and detailed answer reviews.

🎯 Objectives

- Provide an interactive online quiz experience.
- Support multiple quiz categories.
- Evaluate user knowledge automatically.
- Display scores and performance summaries.
- Save the user's best score locally.

✨ Features

- 📚 Multiple quiz categories:
  - HTML
  - CSS
  - JavaScript
  - RDBMS
  - General Knowledge
- ❓ Multiple-choice questions with multiple-answer selection.
- 🔀 Randomized question and option order.
- ⏱️ Countdown timer with automatic submission.
- 📊 Automatic score and percentage calculation.
- ✅ Correct and incorrect answer review.
- 📈 Performance summary with attempted and unanswered questions.
- 🏆 Best score saved using Local Storage.
- 🔄 Restart quiz and switch categories.
- 📱 Responsive design for mobile and desktop.
- 🌙 Modern dark-themed user interface.

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in a web browser.
4. Select a quiz category.
5. Click Start Quiz.
6. Answer the questions before the timer expires.
7. Submit the quiz and review your results.

🧠 How It Works

1. The user selects a quiz category.
2. Questions and answer options are randomized.
3. The countdown timer starts.
4. The user selects one or more answers where applicable.
5. The application calculates the score after submission.
6. The result page displays performance statistics and answer explanations.
7. The best percentage is saved in Local Storage.

📱 Browser Compatibility

The application is designed to work in modern web browsers, including Google Chrome, Microsoft Edge, and Firefox.

⚠️ Limitations

- Scores are stored locally on the user's browser and are not synchronized between devices.
- A shared online leaderboard requires a backend and database.
- The included question bank contains sample questions that can be expanded.
